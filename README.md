# Погодный дайджест

Консольная утилита на Node.js (CommonJS) для получения прогноза погоды. Принимает
один или несколько городов, получает данные из открытого REST API
[Open-Meteo](https://open-meteo.com/) (ключ доступа не требуется), выводит
результат в терминал и сохраняет отчёт в файл `reports/{город}-{ГГГГ-ММ-ДД}.json`.

## Требования к окружению

- Node.js **20+** (используются встроенные `fetch`, `node:test`,
  `process.loadEnvFile`).
- Внешние npm-зависимости не требуются — сторонние HTTP-клиенты (axios и аналоги)
  не используются.

## Установка

```bash
git clone <url>
cd Console_utility
npm install   # необязательно — внешних зависимостей нет
```

При необходимости скопируйте `.env.example` в `.env` (см. «Переменные окружения»).

## Переменные окружения

Настраиваемые параметры задаются в файле `.env` (шаблон — `.env.example`):

| Переменная | По умолчанию | Описание |
| --- | --- | --- |
| `WEATHER_TIMEOUT_MS` | `5000` | Таймаут HTTP-запроса, мс |
| `WEATHER_REPORTS_DIR` | `reports` | Каталог для сохранения отчётов |
| `WEATHER_UNITS` | `metric` | `metric` (Цельсий, мм) или `imperial` (Фаренгейт, дюймы) |
| `WEATHER_GEOCODING_URL` | `https://geocoding-api.open-meteo.com/v1/search` | Базовый URL геокодинга |
| `WEATHER_FORECAST_URL` | `https://api.open-meteo.com/v1/forecast` | Базовый URL прогноза |

## Команды запуска

```bash
node src/index.js --city <города> [опции]
```

Параметры:

| Параметр | Обязательный | Описание |
| --- | --- | --- |
| `--city <города>` | да | Один или несколько городов через запятую |
| `--days <n>` | нет | Количество дней прогноза, 1–7 (по умолчанию 3) |
| `--no-cache` | нет | Игнорировать сохранённый отчёт и запросить заново |
| `-h`, `--help` | нет | Показать справку |

Примеры:

```bash
node src/index.js --city "Нижний Новгород" --days 3
node src/index.js --city "Москва, Санкт-Петербург"
node src/index.js --city Лондон --no-cache
node src/index.js --city "Казань" --days 1
```

Либо через npm-скрипт:

```bash
npm start -- --city "Нижний Новгород" --days 3
```

## Пример вывода в консоль

```text
=== Нижний Новгород ===
Страна: Россия
Координаты: 56.33, 44.00

Дата         Мин.     Макс.    Осадки
2026-09-13   10.3°C   16.4°C   0.0 мм
2026-09-14   9.1°C    18.5°C   0.0 мм
2026-09-15   10.6°C   17.6°C   0.0 мм
```

Отчёт также сохраняется в `reports/Нижний Новгород-2026-09-13.json`.
При ошибке по одному из городов он выводится отдельным блоком, остальные города
продолжают обрабатываться:

```text
=== НетТакогоГорода12345 ===
Ошибка: Город не найден: НетТакогоГорода12345
```

## Обрабатываемые ошибки и коды завершения

| Ситуация | Сообщение |
| --- | --- |
| Отсутствующий/некорректный аргумент | понятная ошибка + подсказка `--help` |
| Город не найден (пустой геокодинг) | `Город не найден: …` |
| HTTP 4xx | `API вернул ошибку клиента (HTTP …)` |
| HTTP 5xx | `API вернул ошибку сервера (HTTP …)` |
| Отсутствие сети | `Отсутствует сеть или не удалось выполнить запрос: …` |
| Превышение таймаута | `Превышен таймаут запроса (… мс)` |
| Некорректный JSON | `Некорректный JSON в ответе API: …` |

Коды завершения:

| Код | Значение |
| --- | --- |
| `0` | успех (все города обработаны) |
| `1` | ошибка (неверные аргументы или хотя бы один город не обработан) |

## Структура проекта

```
Console_utility/
├── src/
│   ├── index.js          # разбор аргументов и запуск
│   ├── cli.js            # парсер аргументов
│   ├── config.js         # загрузка .env и конфигурации
│   ├── errors.js         # типы ошибок
│   ├── api/              # клиент внешнего API
│   │   ├── client.js     # HTTP-клиент (fetch + AbortController)
│   │   ├── geocoding.js  # геокодинг Open-Meteo
│   │   └── forecast.js   # прогноз Open-Meteo
│   ├── services/         # бизнес-логика
│   │   └── weather.js    # обработка одного города (кэш → API → отчёт)
│   ├── storage/          # файлы и кэш
│   │   └── report.js     # пути, чтение/запись JSON, кэш
│   └── format/           # вывод
│       └── console.js    # форматирование в консоль
├── test/                 # тесты (node:test)
├── .env.example          # шаблон переменных окружения
└── package.json
```
